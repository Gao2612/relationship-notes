## 项目概述

关系手记把导入的微信/QQ 聊天记录整理成联系人档案、逐日互动证据和关系分析，并辅助起草回复。

- **本地优先**：聊天、档案、草稿和本人画像保存在浏览器本机 IndexedDB；只有在你启动 AI 功能时，相应上下文才会交给 DSH 配置的模型服务。
- **证据可核对**：每个分数、画像条目、话题与复盘依据都能打开原消息及前后文，误识别可以排除和恢复。
- **不做好感概率**：所有指数概括的是可观察的互动过程，不是“对方喜欢你的概率”。

## 主要功能

### 当前功能

**关系分析 v3（主分析）**

- 按周评估六个有研究依据的互动维度：回应性、自我开示、相互性、积极回应、主动投入、语言同步，并以摩擦与修复折减综合指数。
- 规则层可复核、可重复；每个维度按证据量向中性收缩，给出 80% 区间，没有聊天的周显示为缺口。
- 可选的 AI 上下文评定：每个评分必须逐字引用原文（宿主校验），以有限权重融合，与规则分歧时提示核对，不能单独触发边界封顶。
- 长期变化：EWMA、加权趋势与区间、变化点与阶段，并指出主要变化来自哪些维度。
- 证据分为原文事实 / AI 引用 / AI 推断三栏，均可打开原文上下文。规则与公式见[评分与分析规则](#评分与分析规则关系分析-v3)。

**规则识别与人工纠正（v3 规则层的输入）**

- 上下文评分结合上一轮问题、建议与话题，识别回答、接受建议及承接信息，并按有效回应回合计分。
- 单次应和与笑声按中性处理，连续三轮缺少有效回应才触发短回复处罚。
- 口语分享支持主语变化和自然表达，排除系统消息、媒体及纯占位文本。
- 互动评分页展示全部记录的关系指数与维度估计、正向表达证据及工作、日常、混合场景统计；正向表达标明礼貌、支持与亲近层级。
- 结合上一轮感受或好消息识别支持性回应，感受分享与普通事实分享分别计权。
- 十类识别支持核对原文、排除和恢复，纠正后所有页面的关系指数立即重算。
- 正向信号按回合去重（同一回合只取最强层级）；回复时延与消息长度只作描述，解释和致歉只会减轻摩擦。
- 「打分依据」把当天指数拆成六个维度的贡献、摩擦系数与边界封顶，合计与指数一致；日、周、月、年与全部记录使用同一公式（见[评分与分析规则](#评分与分析规则关系分析-v3)）。

### 档案与沟通功能

- 画像、评分、话题与复盘依据可打开原消息及前后文。
- 联系人资料和本人计划支持有效期、完成、取消、过期与重新打开；结束的计划退出当前建议和模型上下文。
- 编辑后的草稿可明确保存为本人表达样例，并撤销本次保存。
- 话题可标记“已经聊过 / 不合适”，隐藏并可恢复。
- 行为记录新增周/月复盘，汇总真实话题、未见后续回应的问题及当前跟进项。
- 设置可预览并限定 DSH 共享日期和条数，应用后需重新授权。
- 新消息使用持久 ID，旧引用兼容；新增独立视图和自动交付清单。

详见 [功能与入口说明](docs/FEATURES-3.2.md)。界面截图含真实联系人与聊天内容，仓库不公开截图。

### 功能清单

主要功能与入口如下。

1. **联系人档案**：查看并确认模型提议的档案事实，分别呈现沟通风格、边界、待跟进与推测线索；支持有效期、归档与删除。
2. **关系分析**（新，「记录与评分」默认页）：六维度周评估、综合指数与 80% 区间、AI 评定、长期趋势与变化点、三栏证据。
3. **每日历程**：按天查看关系指数（v3）、日历、日/月/年趋势图、真实话题与“未见后续回应”的问题，可展开原消息及前后文。
4. **互动评分**：查看全部记录的关系指数与维度估计、正向表达条数、回答和承接回合，以及分场景结果；展开依据查看表达层级，并排除、恢复误识别。
5. **评分规则 / 打分依据**：查看 v3 的公式、权重、参数与识别规则；按天拆解指数的每个维度贡献、摩擦与边界，并给出所在周和所在月的结果。
6. **记录列表**：分页、搜索、倒序浏览全部聊天记录，并回到原文定位。
7. **会话**：按联系人浏览完整对话、图片与语音；右侧固定草稿区、相关页面与编辑区。
8. **沟通辅助**：用真诚 / 轻松 / 简短三种风格生成候选草稿，附引用与不确定性说明，可保存为本人样例。
9. **话题建议**：生成可聊话题，标记“已经聊过 / 不合适”并隐藏，可随时恢复。
10. **行动计划**：手动添加目标，设置有效期，标记完成、取消、过期与重新打开。
11. **周月复盘与设置**：汇总真实话题、悬空问题与跟进项；设置含模型选择、字号密度、备份导出/恢复、DSH 共享范围预览。

## 界面与操作

2026-11 的界面更新保持全部既有功能与数据结构不变。

- **视觉系统**：青瓷（操作与选中）、藕荷（只用于关系脉搏）、黛蓝（AI）、琥珀（推断/待核对）、朱砂（拒绝与摩擦）。颜色全部由宿主背景/前景派生，浅色与深色主题一致；数字使用旧式衬线（Palatino / Georgia）。
- **关系身份条**：页头显示对方头像与名字、消息数、最近聊天日期，以及最近 20 周互动指数折线和最新值，点击进入关系分析。
- **导航**：一级导航带线性图标；手机宽度下移到屏幕底部的固定标签栏（适配安全区）。
- **层级**：特写卡（首次引导、关系分析总览）> 平面分区 > 浅底条目；阴影只用于菜单、提示条、抽屉等浮层。
- **导入**：支持拖放文件；只有两位发言人且能识别“我”时自动预选身份，可用「⇄ 交换」对调；来源筛选（全部 / 微信 / QQ）为分段控件，无记录的来源自动禁用。
- **会话**：窄屏（≤900px）会话列表以抽屉浮出，点遮罩或 Esc 关闭，「☰ 列表」按钮状态与实际可见性一致；宽屏下「工具」可收起右栏。回复意图输入框支持 Ctrl/⌘ + Enter 生成。
- **提示与动效**：状态提示为底部浮动提示条（普通提示 6 秒后收起，错误保留）；页面切换一次短淡入；遵循 `prefers-reduced-motion`；保留 44px 命中区，对比度 ≥4.5:1。

## 安装

### 安装已构建的 ZIP

使用发布或本地构建生成的安装 ZIP，解压到单独目录，确认目录内有 `package.json`、`index.js`、`client.js` 和 `cordis.patch.yml`。在 DSH 本地插件安装/加载入口选择该目录，启用关系手记及其「定制模块」容器依赖，然后重载宿主插件服务；若当前 DSH 没有重载入口，重启 DSH。安装包已包含 `client.js`，无需运行 pnpm 安装、构建或测试。

升级前先导出关系手记备份。用新解压目录更新本地插件加载位置并重载宿主服务；只刷新页面可能仍使用旧宿主路由（例如关系分析需要的 `/affinity-analysis` 路由）。随后在「定制模块」打开关系手记。安装 ZIP 是运行包，不包含完整构建/测试工具；开发请使用源码仓库。

### 从源码构建与验证

取得完整源码（包括 `build.mjs`、`verify-v3.mjs`、`pnpm-lock.yaml` 和测试文件），使用 Node.js 和 pnpm。验证环境为 Node.js 22。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm test
```

构建使用显式 ESM 模块与 esbuild，不依赖仓库之外的原型文件。`client.js` 是仓库跟踪的生成产物，修改客户端源码后需重新构建并同步提交；安装包附带该产物。源码分层与依赖方向见 [架构与维护边界](docs/ARCHITECTURE.md)。

### 发布打包

构建后可先预览交付文件，再生成安装包。

```sh
node tools/package-release.mjs --out <新的输出目录> --dry-run
node tools/package-release.mjs --out <新的输出目录>
```

打包工具只用 Node.js 内置模块写 ZIP，Windows、macOS 与 Linux 均可运行。它按发布文件清单选取内容，排除依赖、测试与历史归档，生成 ZIP、SHA256 和逐文件清单。已有同名输出会拒绝覆盖，源码晚于客户端产物时需先重新构建。

## 使用

- 在 DSH「定制模块」打开关系手记，导入聊天文件（可拖放）并确认双方身份。
- 在联系人档案中核对模型待确认条目，再接受、编辑、归档或删除。沟通风格、边界、待跟进和推测线索分别呈现。
- 在「记录与评分 → 关系分析」查看规则层结果；点击「AI 分析」可让 DSH 模型逐周评定（可随时取消），结果按周缓存。
- 在设置中维护“我”的语气、口癖、兴趣、计划、边界和认可样例。回复生成参考这些信息以及真诚表达、尊重边界、不用试探测试关系等原则。
- 互动评分可以展开原文，标记误识别并恢复；关系指数概括可观察的互动过程，不是好感概率。
- 回复栏可选择真诚/轻松/简短风格，并主动生成带引用和不确定性的多种可能解释及回复思路。
- 需要 DSH 主对话读取资料时，显式开启“允许 DSH 读取当前联系人”。可读取已确认档案、搜索最近最多 500 条共享消息，并提出待确认候选。共享范围是当前本机 DSH 宿主中的工具对话，参见 [档案工具说明](docs/PROFILE-TOOLS.md)。
- 项目备份可以选择包含或不包含媒体；旧版备份仍可恢复。

微信/QQ 监听、独立替代 ExportWeChat 读取、自动发送和主动搭话暂缓开发，只有 [研究方案](docs/CAPTURE-RESEARCH.md)。现有 ExportWeChat JSON/HTML 文件导入继续可用。

## 评分与分析规则（关系分析 v3）

关系分析 v3 是插件唯一的评分系统：「关系分析」「每日历程」「互动评分」「打分依据」「评分规则」、月/年图表、页头关系脉搏与关系阶段都使用本节的公式（各页面的粒度见[下文](#各页面使用的粒度)）。本节与代码逐项对应：`src/affinity/`（规则层、模型、长期变化）与 `affinity-service.js`（AI 路由与校验），模型版本 `3.0`。

v3 不输出单一的“好感分”。它按时段评估六个有研究依据的互动过程，加上摩擦与修复，再把规则统计、AI 上下文评定、长期变化和逐条原文证据放在同一页。所有指数概括的是**可观察的互动过程**，不是“对方喜欢你的概率”，也不诊断依恋类型或人格。

### 计算流程

1. **回合与时段**：消息合并为回合，按时段（日、周、月、年或全部记录；周从周一开始，上海时区）汇总双方可观察的互动事实。
2. **规则层**：计算六个维度的原始值 $x$（0–1）与证据量 $n$，以及摩擦强度和边界。
3. **收缩**：每个维度按证据量向中性值 0.5 收缩，并给出标准误。
4. **AI 层（可选）**：用户点击「AI 分析」后，模型逐周按锚定量表评定；只有附逐字引用的评分才以有限权重融合。
5. **综合指数**：加权平均 × 摩擦折减，明确边界的周封顶 30，并给出 80% 区间。
6. **长期变化**：缺口、EWMA、趋势、变化点与阶段。
7. **解释**：每个维度分为原文事实 / AI 引用 / AI 推断三栏，均可打开原文上下文。

### 回合、对话段与周

- 评分只使用双方的文本消息，排除系统消息、非文本媒体记录及纯占位文本（与每日评分相同）。
- 同一人连续发送、相邻间隔不超过 3 分钟的消息合为一个回合；首次发言或与上一回合末尾间隔达到 120 分钟时开启新对话段，该回合记为一次“主动开启”。
- 时间按上海时区归入日期，再归入以周一开始的周、月和年。没有任何消息的时段不生成评分，显示为缺口；对方没有任何回合的时段不评分（显示“未评分”）。两者都不是 0 分。
- 对方回合的回答、承接、摩擦、解释、敷衍与低信息量判定，以及十类人工纠正，继承自原有的识别规则（完整条款见插件「评分规则」页的“识别规则”）。纠正后所有页面立即重算。
- v3 在此基础上补充三项：我方“连接邀请”后的转向（含支持与追问）、我方好消息情境、常见致歉/澄清说法作为修复（只会减轻摩擦）。

**连接邀请（bid）**：我方提问或分享的回合。对方下一回合的回应分为四类：

| 类别 | 条件 |
| --- | --- |
| 未回复 | 下一回合不是对方，或间隔 ≥ 24 小时；不计入回应性分母（文字聊天可异步） |
| 对立 against | 对方回合含明确拒绝/边界或摩擦 |
| 转向 toward | 对方回答或承接；或表达支持/具体感谢（正向权重 ≥ 4）；或在同一对话段内就该话题追问 |
| 转离 away | 其他情况（可能是自然的话题切换，也可能漏判） |

**好消息情境**：我方回合含第一人称“我”且命中好消息词（如“通过了”“拿到”“升职”“终于”），且对方 24 小时内回应时，记为一次机会；若对方回应无摩擦，且为支持/具体感谢（正向 ≥ 4），或在提问、回答/承接的同时带有正向表达（正向 ≥ 1），记为积极建设性回应。

### 六个维度与规则层公式

记对方回合数为 $t$，各计数均为“回合数”（同一回合同类信号只计一次）。

| 维度 | 权重 | 规则层原始值 $x$ | 证据量 $n$ | 主要依据 |
| --- | --- | --- | --- | --- |
| 回应性 | 0.28 | toward ÷ (toward + away + against) | 我方连接邀请中已回复的次数 | Reis 等 2004；Laurenceau 等 1998；Gottman & Driver 2005 |
| 自我开示 | 0.18 | min(1, (对方分享 + 0.5 × 对方感受分享) ÷ (0.6 × $t$)) | $t$ | Collins & Miller 1994；Laurenceau 等 1998 |
| 相互性 | 0.16 | 分享率、提问率、主动开启次数三项各取 $1-\lvert a-b\rvert/(a+b)$ 后平均 | 双方分享、提问、开启次数之和 | Sprecher 等 2013 |
| 积极回应 | 0.14 | 0.5 × min(1, 对方正向分值 ÷ 2$t$) + 0.5 × 好消息获积极回应比例；没有好消息情境时只用前一项 | $t$ + 好消息机会数 | Gable 等 2004 |
| 主动投入 | 0.14 | 对方主动开启占比与 min(1, 对方邀请回合 ÷ 0.5$t$) 的平均 | 双方开启次数 + $t$ | Gottman & Driver 2005；Stafford & Canary 1991 |
| 语言同步 | 0.10 | 九类虚词每 100 字使用率的 $1-\lvert p_1-p_2\rvert/(p_1+p_2)$ 平均（LSM，中文近似词表，最长匹配）；任一方少于 40 字不计算 | min(12, ⌊较少一方字数 ÷ 20⌋) | Ireland 等 2011 |

- 相互性中的分享率、提问率为“该类回合 ÷ 本方回合”，主动开启直接比较次数；只看是否对等，不看谁多。
- 对方正向分值：每回合取最强的正向表达，礼貌/表情 1、支持或具体感谢 4、直接亲近 6。
- 对方邀请回合：对方提问或分享的回合。
- 某一维度没有可计算的数据时，$x$ 记为缺失，收缩后为 0.5。
- 回复时延与消息长度不进入任何维度（回复慢、消息短与沟通习惯和依恋差异有关，Morey 等 2013）。

**摩擦与修复**（不是加权维度，而是对综合指数的折减）：

$$
F_{\text{raw}}=\min\!\left(1,\ \frac{2\,(c+0.5\,e)}{\max(4,t)}\right),\qquad
F_{\text{rule}}=F_{\text{raw}}\times(1-0.5\,\rho),\qquad \rho=\min\!\left(1,\frac{r}{c}\right)
$$

其中 $c$ 为对方摩擦回合，$e$ 为敷衍或低信息量回合，$r$ 为解释、和解或常见致歉回合（$c=0$ 时 $\rho=0$）。依据：Gottman & Levenson 1992；Salvatore 等 2011。

**边界**：对方回合中存在未被人工排除的明确拒绝、停止联系等表达时，该周触发边界封顶。

### 收缩与区间

每个维度按 Beta-二项式的经验贝叶斯形式向中性先验 0.5 收缩（$k=4$）：

$$
\hat d=\frac{n\,x+k\cdot0.5}{n+k},\qquad \mathrm{SE}=\sqrt{\frac{\hat d\,(1-\hat d)}{n+k}}
$$

样本少时估计自然接近 0.5，不会因为一两句话给出极端值。摩擦的先验为 0（没有证据时视为无摩擦）：$\hat F=\dfrac{t\,F_{\text{rule}}}{t+4}$。

### AI 上下文评定与融合

用户点击「AI 分析」后，插件逐周把聊天交给 DSH 配置的模型（路由 `POST /api/relationship-notes/affinity-analysis`，温度 0.1，最多 3500 tokens，超时 90 秒），可随时取消。

- **发送内容**：每周最多 80 条消息，每条最多 300 字。超出时优先保留对方含分享、摩擦、修复、边界、强正向（≥ 4）或提问的回合及其前一轮我方消息，其余按时间均匀抽样，并告知模型抽样比例。上一周的 AI 摘要作为背景传入（不可作为证据）。没有对方消息的周不发送。
- **量表**：回应性、自我开示、相互性、积极回应、主动投入与摩擦各给 1–5 的整数，证据不足时为 null；置信度为低/中/高。摩擦方向相反（1 = 无摩擦），并给出本周摩擦后是否已修复（repaired）。提示词为每个维度提供 1 / 3 / 5 锚点。
- **输出要求**：每个非 null 评分附 1–3 条引用，引用必须是对应消息原文中逐字连续的片段；note 只描述这句话做了什么；inference 写可能的解释，必须使用不确定措辞，alternatives 至少给出一种其他解释。
- **宿主校验**（不合格即整周拒绝，返回 502）：维度白名单；评分为 1–5 整数或 null；置信度枚举；非 null 评分至少一条引用；引用逐字匹配；边界引用只能来自对方；拒绝好感概率或百分比、“肯定/一定/证明……喜欢你”等确定性措辞，以及依恋类型或人格诊断。

AI 评分 $r$ 映射为 $a=(r-1)/4$，置信度权重 $c_{\text{AI}}\in\{0.5,\,1,\,1.5\}$（低/中/高），伪计数 $m=4\,c_{\text{AI}}$：

$$
\tilde d=\frac{n\,x+k\cdot0.5+m\,a}{n+k+m},\qquad
d=\hat d+\mathrm{clip}\big(\tilde d-\hat d,\ -0.25,\ 0.25\big),\qquad
\mathrm{SE}=\sqrt{\frac{d\,(1-d)}{n+k+m}}
$$

- 没有引用或 rating 为 null 的 AI 评分不参与，该维度只用规则层。语言同步不接受 AI 评分。
- 规则层有值、$n\ge3$ 且 $\lvert a-x\rvert>0.35$ 时，标记“规则与 AI 不一致，请核对”。
- 摩擦同样融合（先验 0），偏移上限同为 ±0.25；AI 判定“已修复”时摩擦再 × 0.75。
- **边界只由规则层触发封顶**。AI 单独识别到边界时，只提示人工核对，不改变指数。
- 结果按周缓存在联系人数据中，并绑定该周消息的指纹；该周聊天新增或编辑后，自动变为待分析（人工纠正只影响规则层，规则层结果会立即重算）。连续两周请求失败时停止，避免在模型不可用时逐周重复请求。

### 综合指数、区间与可信度

$$
P=\frac{\sum_k w_k d_k}{\sum_k w_k},\qquad
\mathrm{SE}_P=\frac{\sqrt{\sum_k (w_k\,\mathrm{SE}_k)^2}}{\sum_k w_k},\qquad
I=100\times P\times(1-0.6\,F)
$$

- 80% 区间：$100\times\mathrm{clip}(P\mp1.2816\,\mathrm{SE}_P,\,0,\,1)\times(1-0.6F)$。
- 存在规则层边界的时段，指数和区间上下限都不超过 30。指数四舍五入为整数（0–100）；对方没有回合的时段为未评分（null）。
- 可信度：对方回合 ≥ 20 且回应性证据 ≥ 5 为“高”；对方回合 ≥ 8 为“中”；其余为“低”。

权重按理论重要性排序但接近等权：回应性是亲密过程的核心中介（0.28），开示、相互性、积极回应、主动投入其次，语言同步因中文词表为近似、证据来自单一研究，权重最低（0.10）。在没有带标签数据拟合时，这类“不当线性模型”比主观精细调参更稳健（Dawes 1979）。权重**尚未用真实结果校准**。

### 长期变化

- **缺口**：没有聊天的周保留为缺口，不参与趋势与变化点计算。
- **平滑**：EWMA，$\lambda=0.3$；缺口周沿用上一周的平滑值。
- **趋势**：最近 ≤ 8 个有数据的周，按权重 $1/\max(4,\mathrm{SE}^2)$ 做加权最小二乘，斜率单位为“分/周”，给出 80% 区间；至少 4 周才计算。区间下限 > 0 且斜率 ≥ 1 为“上升”，区间上限 < 0 且斜率 ≤ −1 为“下降”，其余为“稳定”。
- **变化点**：自启动双侧 CUSUM（$k=0.5$，$h=3$），参照值为上一个变化点以来（至少 2 周）的均值；噪声尺度 $\sigma=\max(3,\ \mathrm{MSSD},\ 0.5\times\text{中位 SE})$，MSSD 由相邻周差估计，避免把变化本身算进噪声。至少 6 个有数据的周才启用；变化起点回溯到连续同向偏离的第一周。
- **阶段**：按变化点切分，给出每段的平均指数和各维度均值，并列出影响最大的至多 3 个因素（影响 = 100 × 权重 × 维度变化；摩擦为 −30 × 摩擦变化；只列 |影响| ≥ 0.5 的项）。

这些都是统计描述，不是对关系的结论。

### 可解释证据

每个维度展示定义、规则公式与研究来源，并分三栏：

- **原文事实**：规则层统计与对应原文。每个维度最多 6 条，每种类型最多 2 条，正反两类例子都能看到。
- **AI 引用**：经宿主逐字校验的原文及客观描述。
- **AI 推断**：可能的解释、置信度、替代解释，以不同样式标出。

所有原文都可以打开前后文核对。

### 局限

- 文字缺少语气、表情包语义、语音与线下互动；工作语境、方言、反讽都可能误判。
- 中文 LSM 使用近似虚词表，未分词。
- 权重、饱和参数、收缩强度、偏移上限都是产品参数，没有用真实关系结果校准。
- LLM 评定有随机性，不同模型之间可能不一致。

完整设计、研究来源与后续校准计划见 [关系分析 v3 设计说明](docs/AFFINITY-V3.md)。

### 各页面使用的粒度

所有粒度使用同一套规则层公式。连接邀请、好消息情境与主动开启都归入发起回合所在的时段，LSM 由虚词计数计算，因此按日汇总后再相加，与直接按周、月、年计算的结果完全一致。

| 页面 / 用途 | 粒度 | 说明 |
| --- | --- | --- |
| 关系分析、页头关系脉搏 | 周 | 规则层 + 已缓存的 AI 评定（只有周粒度融合 AI） |
| 每日历程（日历、日趋势）、打分依据 | 日 | 当天规则层指数、80% 区间、可信度与六维度拆解 |
| 每日历程（月 / 年趋势、数据表） | 月、年 | 把该时段各日信号相加后整体评分，不是日指数的平均 |
| 互动评分、统计页 | 全部记录 | 合并全部回合评分；分场景结果按场景子集分别评分 |
| 关系阶段 | 最近 30 天 | 窗口内各日信号合并后评分；门槛 朋友 ≥ 45、好朋友 ≥ 55（产品设定，未校准） |
| 回复 / 每日总结的模型载荷 `affinityScore` | 日 | 当天规则层指数，对方当天无回合时为 null |

旧版「好感线索分 v2.x」（38 分起算、逐项加减、少样本向 32 折算）已于 2026-11-17 移除，历史曲线全部按 v3 重算，新旧数值不宜直接比较。

## 数据与模型

聊天、档案、草稿和本人画像保存在浏览器本机 IndexedDB。模型回复、资料整理、历史自动分析或「关系分析」的 AI 分析启动后，相应聊天上下文和资料会交给 DSH 配置的模型服务。自动分析可在状态区暂停或继续。开启档案共享时，当前联系人的有界快照会暂存在宿主内存，关闭/切换后撤销，停止同步后 60 秒过期；宿主不落盘保存此快照。

导入工具使用内存队列；重启前应确认消费完成，见 [导入队列设计](docs/IMPORT-QUEUE-DECISION.md)。备份含聊天资料，应自行妥善保存。仓库不包含用户聊天导出、联系人档案、媒体、凭据或个人备份。

## 国际化（实验性，仅导航文案）

本 README 提供中文、英文与日文版本；插件界面本身以中文为主。

`locale/zh.json` 与 `locale/en.json` 由 `build.mjs` 从 `src/workspace.js` 的 `textPairs` 生成，**目前只覆盖两项**：导航名称（`nav`）与隐私说明（`privacy`，用于模块标题/描述）。

- 其余界面文案、页面标题与按钮仍为中文硬编码，没有英文版本。
- 因此当前不做“完整 i18n”承诺：英文环境只会在导航与模块描述处看到英文，其余保持中文。
- 若要扩展，请在 `textPairs` 增加键值并重新生成 locale（`pnpm run build`），不要手改生成文件。
