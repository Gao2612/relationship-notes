# Relationship Notes for DSH

本地优先的 DSH 沟通辅助插件，支持聊天记录导入、联系人资料、互动线索分析、沟通草稿与按证据生成的续聊建议。所有生成内容都是待编辑草稿，不会自动发送消息。我的表达档案数据结构和证据化续聊建议逻辑已实现；自我档案编辑 UI 尚未开放。

## 安装和构建

1. 安装 Node.js 24 或兼容版本。
2. 执行 `npm install`。
3. 执行 `npm run build`。
4. 按 DSH 的本地插件安装流程加载本包。

当前宿主容器契约为 `inject: ['locale', 'subdsh']`，模块注册 id 为 `relationship-notes`。插件构建需要同级的 `relationship-plugin-prototype/index.html` 基线文件；此文件不随本源码包分发，需在本地构建时从对应 DSH 工作区提供。

## 隐私

聊天、联系人档案、草稿和自我画像默认保存在浏览器本机 IndexedDB。调用 DSH 模型生成内容时，当前对话上下文、已确认资料、自我画像和建议会发送到用户配置的模型服务。不要填写不希望交给该模型服务的内容。项目备份包含聊天和媒体副本，应妥善保管。

仓库不接收或附带真实聊天记录、联系人资料、导出文件、备份或本机日志。互动分数只是由明确消息线索构成的参考指标；模型对想法和后续回应的猜测都不是事实或可靠预测。

## 功能边界

- 目前支持导入现有聊天文件和 DSH 用户主动触发的聊天导入。
- 没有微信/QQ 前台窗口监听或自动发送能力。
- 草稿、话题与分析由用户检查、编辑并自行决定是否使用。
