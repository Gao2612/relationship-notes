# Relationship Notes for DSH

关系手记 3.2.0：本地优先的联系人档案、互动证据与沟通草稿插件。

## 3.2 新增

- 画像、评分、话题与复盘依据可打开原消息及前后文。
- 联系人资料和本人计划支持有效期、完成、取消、过期与重新打开；结束的计划退出当前建议和模型上下文。
- 编辑后的草稿可明确保存为本人表达样例，并撤销本次保存。
- 话题可标记“已经聊过 / 不合适”，隐藏并可恢复。
- 行为记录新增周/月复盘，汇总真实话题、未见后续回应的问题及当前跟进项。
- 设置可预览并限定DSH共享日期和条数，应用后需重新授权。
- 新消息使用持久ID，旧引用兼容；新增独立视图和自动交付清单。

详见 [功能与入口说明](docs/FEATURES-3.2.md)。界面截图含真实联系人与聊天内容，仓库不公开截图。

## 功能清单

一级入口与每页能做什么（共 10 条）：

1. **联系人档案**：查看并确认模型提议的档案事实，分别呈现沟通风格、边界、待跟进与推测线索；支持有效期、归档与删除。
2. **每日历程**：按天查看互动评分、真实话题与“未见后续回应”的问题，可展开原消息及前后文。
3. **互动评分**：查看评分指数与证据来源，标记误识别并恢复；指数是表达线索汇总，不是好感概率。
4. **评分规则**：查看公式、权重与条款，可展开逐句解释。
5. **记录列表**：分页、搜索、倒序浏览全部聊天记录，并回到原文定位。
6. **会话**：按联系人浏览完整对话、图片与语音；右侧固定草稿区、相关页面与编辑区。
7. **沟通辅助**：用真诚 / 轻松 / 简短三种风格生成候选草稿，附引用与不确定性说明，可保存为本人样例。
8. **话题建议**：生成可聊话题，标记“已经聊过 / 不合适”并隐藏，可随时恢复。
9. **行动计划**：手动添加目标，设置有效期，标记完成、取消、过期与重新打开。
10. **周月复盘与设置**：汇总真实话题、悬空问题与跟进项；设置含模型选择、字号密度、备份导出/恢复、DSH 共享范围预览。

## 评分规则（当前版本）

好感线索分由本地规则计算，不调用模型，可逐项复核（页面「评分规则」「打分依据」两页与本段一致）。

### 计算公式

$$
S=\operatorname{clamp}\!\Big(\operatorname{round}\big(38+W-C+I+L-P-T-T_{\mathrm{thin}}\big),\,0,\,100\Big),
\qquad
S\leftarrow\min(S,\,48)\quad(\text{当日判定为「真吵起来」})
$$

$$
\begin{aligned}
W&=\min\!\Big(45,\ \min\big(T_t\ge 2\ ?\ 24:12,\ 12\,n_{\mathrm{pos}}\big)+8\,n_q+6\,n_{\mathrm{sh}}\Big) &&\text{正向}\\
C&=\min\!\Big(60,\ 24\,n_{\mathrm{bnd}}+\operatorname{round}(32E)+5\,n_{\mathrm{slow}}+\max\big(18\,[N_t=0\wedge N_s>0],\ 24\,[T_t=0]\big)\Big) &&\text{负向}\\
E&=\min\!\Big(1,\ \frac{n_{\mathrm{perf}}+n_{\mathrm{low}}}{T_t}\Big) &&\text{敷衍率}\\
I&=\operatorname{round}\!\Big(\big(\tfrac{S_t}{S_t+S_s}-\tfrac12\big)\times 20\Big)\in[-10,10] &&\text{主动开口偏向}\\
L&=6\,[m\le 10]+3\,[10<m\le 30]-7\,[120<m\le 360]-12\,[m>360] &&\text{中位回复间隔 }m\text{（分钟）}\\
P&=8\,[\rho<0.2]+4\,[0.2\le\rho<0.35],\quad \rho=\frac{\min(N_s,N_t)}{\max(N_s,N_t)} &&\text{条数失衡}\\
T&=\min\!\Big(12,\ 12\,n_c\Big)+[\,\mathrm{strong}\,]\cdot\Big(\min\big(60,30\min(2,n_c)+10\min(3,n_a)\big)-\min(12,12n_c)\Big) &&\text{摩擦}\\
T_{\mathrm{thin}}&=\min\!\Big(16,\ 8\min(2,N_s'-1)\Big)\cdot[\,N_s'\ge 2\wedge T_t=1\,] &&\text{独白式冷场}\\
\mathrm{strong}&:\ (n_c\ge 2)\ \vee\ (n_c\ge 1\wedge n_a\ge 1) &&\text{真吵起来}
\end{aligned}
$$

其中 $[\,\cdot\,]$ 表示示性函数（条件成立取 1，否则取 0）。

变量：`pos` 正向措辞句数、`q` 对方提问次数、`share` 对方自我分享次数、`bnd` 负向/拒绝措辞句数、`perfunctory` 敷衍回合、`lowContent` 低信息量回合、`slow` 超过 2 小时才回的条数、`targetStarts/selfStarts` 对方/我方先开口次数、`c` 反讽赌气句数、`a` 事后解释条数、`targetTurns/selfTurns` 双方发言回合数；`oneSided`＝对方零条而我方有消息取 18、`silent`＝对方零回合取 24（两者取大不叠加）。

### 分项说明

- 起算：当天有聊天记录即从 **38 分**起算，结果限制在 **0–100**。
- 正向：正向措辞（对方 ≥2 轮时最多认 2 句，**+12/句**，即最多 +24；只回 1 轮最多认 1 句）＋ 对方每次提问 **+8** ＋ 对方每次自我分享 **+6**，正向合计最多 **+45**。
- 负向：负向/拒绝措辞每次 **−24**。
- 摩擦：反讽/赌气 **−30/次**（最多计 2 次），事后解释 **−10/条**（最多 3 条，抵消一部分而非归零）；未判成真吵时只按 **−12/次** 记，合计最多 −12。判定为「真吵起来」的当天**总分封顶 48**。
- 敷衍：**−32 ×（敷衍＋低信息量回合 ÷ 对方发言回合）**。
- 回复速度：超过 2 小时才回 **−5/次**；中位间隔 ≤10 分钟 **+6**、≤30 分钟 **+3**、>6 小时 **−12**。
- 失衡：对方整天零回合 **−24**（与「单方独白 −18」取较大值，不叠加）；对方只回 1 轮而我方仍连发 **−8~16**；另有主动开口偏向。
- 兜底：各项扣分合计最多 **−60**，结果再夹到 0–100。
- 提问判定：句末问号、句末「吗」，或明确征询句式（干嘛/在哪儿/几点/多少/为什么/要不要/能不能/会不会/是不是/对不对/好不好/有没有/行不行/在不在/怎么样）。只是出现「啥/咋/几天/什么」的陈述句不算提问。
- 低频日：对方整天零回合，或当天来回不足 4 条且没有正负向与敷衍证据，直接记中性 **32 分**。
- 汇总：月/年按当天「对方发言回合数」加权（对方没开口的日子只记 1 份权重）；当月对方回合合计不足 20 轮时，高于 32 的部分按「回合数 ÷ 20」向 32 折算，小样本撑不起高分。
$$
\bar S=\frac{\sum_d S_d\,w_d}{\sum_d w_d},\qquad
w_d=\max\big(1,\ T_t^{(d)}\big),\qquad
\bar S'=\begin{cases}\bar S, & \sum_d w_d\ge 20\\[2pt] 32+(\bar S-32)\cdot\dfrac{\sum_d w_d}{20}, & \sum_d w_d<20\end{cases}
$$
- 口径差异：好感线索分与「互动均衡分」不是同一标尺——后者只比较双方发言条数，不可直接相比。

## 使用

- 在 DSH「定制模块」打开关系手记，导入聊天文件并确认双方身份。
- 在联系人档案中核对模型待确认条目，再接受、编辑、归档或删除。沟通风格、边界、待跟进和推测线索分别呈现。
- 在设置中维护“我”的语气、口癖、兴趣、计划、边界和认可样例。回复生成参考这些信息以及真诚表达、尊重边界、不用试探测试关系等原则。
- 互动评分可以展开原文，标记误识别并恢复；指数是表达线索汇总，不是好感概率。
- 回复栏可选择真诚/轻松/简短风格，并主动生成带引用和不确定性的多种可能解释及回复思路。
- 需要 DSH 主对话读取资料时，显式开启“允许 DSH 读取当前联系人”。可读取已确认档案、搜索最近最多 500 条共享消息，并提出待确认候选。共享范围是当前本机 DSH 宿主中的工具对话，参见 [档案工具说明](docs/PROFILE-TOOLS.md)。
- 项目备份可以选择包含或不包含媒体；旧版备份仍可恢复。

微信/QQ 监听、独立替代 ExportWeChat 读取、自动发送和主动搭话暂缓开发，只有 [研究方案](docs/CAPTURE-RESEARCH.md)。现有 ExportWeChat JSON/HTML 文件导入继续可用。

## 国际化（实验性，仅导航文案）

`locale/zh.json` 与 `locale/en.json` 由 `build.mjs` 从 `src/workspace.js` 的 `textPairs` 生成，**目前只覆盖两项**：导航名称（`nav`）与隐私说明（`privacy`，用于模块标题/描述）。

- 其余界面文案、页面标题与按钮仍为中文硬编码，没有英文版本。
- 因此当前不做“完整 i18n”承诺：英文环境只会在导航与模块描述处看到英文，其余保持中文。
- 若要扩展，请在 `textPairs` 增加键值并重新生成 locale（`pnpm run build`），不要手改生成文件。

## 安装已构建的 ZIP

下载发布的安装 ZIP，解压到单独目录，确认目录内有 `package.json`、`index.js`、`client.js` 和 `cordis.patch.yml`。在 DSH 本地插件安装/加载入口选择该目录，启用关系手记及其「定制模块」容器依赖，然后重载宿主插件服务；若当前 DSH 没有重载入口，重启 DSH。安装包已包含 `client.js`，无需运行 pnpm 安装、构建或测试。

升级前先导出关系手记备份。用新解压目录更新本地插件加载位置并重载宿主服务；只刷新页面可能仍使用旧宿主路由。随后在「定制模块」打开关系手记。安装 ZIP 是运行包，不包含完整构建/测试工具；开发请使用源码仓库。

## 从源码构建与验证

取得完整源码（包括 `build.mjs`、`verify-v3.mjs`、`pnpm-lock.yaml` 和测试文件），使用 Node.js 24 和 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm test
```

构建使用显式 ESM 模块与 esbuild，不依赖仓库之外的原型文件。`client.js` 是生成产物，源码仓库不提交；安装包附带生成产物。容器契约是 `inject: ['locale', 'subdsh']`，注册 ID `relationship-notes`。源码分层与依赖方向见 [架构与维护边界](docs/ARCHITECTURE.md)。

## 数据与模型

聊天、档案、草稿和本人画像保存在浏览器本机 IndexedDB。用户主动调用模型时，选定上下文和已确认资料会交给 DSH 配置的模型服务。开启档案共享时，当前联系人的有界快照会暂存在宿主内存，关闭/切换后撤销，停止同步后 60 秒过期；宿主不落盘保存此快照。

导入工具使用内存队列；重启前应确认消费完成，见 [导入队列设计](docs/IMPORT-QUEUE-DECISION.md)。备份含聊天资料，应自行妥善保存。仓库不包含用户聊天导出、联系人档案、媒体、凭据或个人备份。
