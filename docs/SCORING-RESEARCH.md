# 评分研究依据与设计记录

更新：2026-11-07。适用于好感线索评分 v2.1；完整算式见 [README](../README.md#评分规则当前版本)，实际计算位于 `src/interaction-signals.js` 的 `interactionScoreBreakdown()`。

## 评分可以说明什么

该指数整理聊天中能核对的表达与互动行为，帮助用户回到原文复盘。亲密感、关系满意度和“这个人是否喜欢我”是不同的概念。以下研究支持关注某些互动过程，但没有给出将中文微信/QQ记录换算成好感概率的公式。38、32、各项权重和六回合阈值均为本项目的产品参数，未经带标签的真实关系数据训练或校准。

研究检索只使用公开论文与摘要；本地聊天不作为搜索词提交。评分仍在本机执行，不额外调用模型或上传聊天。用户主动启动的草稿、档案和历史模型分析继续遵循 README 中的数据说明。

## 研究与实现的对应

| 研究来源 | 研究发现及范围 | 本次采用的设计 | 适用限制 |
| --- | --- | --- | --- |
| [Laurenceau、Barrett 与 Pietromonaco，1998](https://pubmed.ncbi.nlm.nih.gov/9599440/) | 两项互动日记研究支持自我披露、对方披露和感受到的回应与亲密体验有关；其中一项研究中，情绪披露比事实披露更能预测亲密感。 | 将回答、接受建议和承接话题纳入有效回应项；保留自我分享证据。 | 规则命中只是回应的粗略代理，不能测出理解、认可或关心的主观体验；研究不支持直接确定“每回合加几分”。 |
| [Patel、Mahar 与 Webster，2022](https://pubmed.ncbi.nlm.nih.gov/35085449/) | 对 302 名有恋爱伴侣的大学生的研究显示，消息频率偏好和回应时延与个体依恋差异有关。 | 取消统一的快回奖励、慢回扣分及消息条数失衡处罚；时延仍作为描述统计。 | 不能凭聊天推断依恋类型；这些关联也不意味着时延在任何情境都无信息。本版本缺少个人可用时间与沟通约定，因此不将统一阈值写成好感证据。 |
| [Salvatore 等，2011](https://pubmed.ncbi.nlm.nih.gov/21245491/) | 对 73 名年轻成人及其伴侣的观察研究中，伴侣在冲突后的恢复能力与更积极的关系情绪和更高满意度相关。 | 解释不再增加摩擦扣分，也不再把一次摩擦升级为较强摩擦。较强摩擦只由同段重复摩擦触发。 | 研究测量的是观察到的恢复过程，并非某个道歉或解释词；本实现不会因为一句“没别的意思”自动认定已修复关系。 |
| [Kluger 与 Malloy，2019](https://doi.org/10.1037/pspi0000156) | 对提问与好感研究的速配数据重分析指出，需要区分个人、对象及双方组合效应，质疑直接把提问等同于倾听的解释。 | 提问每回合计一次，给予较低权重和独立上限；结合有效回应，避免仅靠大量问题获得很高分。 | 研究针对特定面对面速配设计；不能据此断言提问无益，也不能将结论直接当作中文消息分类器的准确率。 |

## v2.1 补充

[Algoe 等（2016）](https://journals.sagepub.com/doi/10.1177/1948550616651681)观察到，感谢中具体赞赏伴侣的行为与更强的感知回应相关。[Gable 等（2004）](https://www.sas.rochester.edu/psy/people/faculty/reis_harry/assets/pdf/GableReisImpettAsher_2004.pdf)发现，积极接住好消息与更好的关系体验相关。因此将礼貌、支持和亲近表达分层，并结合上一轮识别安慰或祝贺。感受分享与事实分享分开计权，负面感受也可属于分享。具体权重是产品参数。

## 参数选择与行为

本次保留已有 0–100 显示范围和 32 分少证据参考点，便于历史页面继续使用。正向措辞、提问、自我分享分别按回合去重，独立上限为 18、8、10 分；有效回应项最多 12 分，四项总和最多 45 分。提问与分享可在一个回合同时命中，但同类消息重复发送不会在该回合内累加。

有效回应取“回答或接受建议”和“承接或补充信息”的并集。一个回合两类都命中仍只算一次；保留明确负向或摩擦证据的回合不进入该加分项。人工排除与恢复会同时影响指标和实际得分。

少于六个对方回合时，将高于 32 的部分向 32 收缩，降低单句礼貌用语产生强结论的可能。负向证据不因样本量小而被抬高，明确负向或边界出现时总分最多 32。主动开口只保留小幅加分，沉默、分多条发送、慢回复和解释均不独立扣分。以上处理是保守的产品选择，六个回合并非研究证明的充分样本。

低频覆盖按合并回合判断：有记录、对方零回合或双方总回合不足四个，且没有其他可评分信号时按 32 记。用回合代替原始消息条数，可以避免把一条回复拆成多条气泡就提高分数。正常忙碌、睡觉、晚安和当次聊天收尾不触发短回复处罚，也不累积缺少回应的连续次数。没有指向对方的工作或其他外界压力抱怨不算关系摩擦。

| 情境（虚构） | 新规则的预期行为 |
| --- | --- |
| 问“几点出门？”，答“明天八点” | 依据上下文识别有效回答；短句不因字数少而扣分。 |
| 同一回合连续发“谢谢你”“谢谢你” | 正向措辞回合只计一次，且受小样本折算约束。 |
| 对方晚几个小时回复具体问题 | 时延本身不扣分；若上一轮仍是我方提问，保留该轮上下文进行回答识别。两小时切段仍用于开口与摩擦统计。 |
| 连续说明“在忙”“准备睡了”或正常道晚安 | 按中性收尾处理，不因简短而累积处罚。 |
| “客户的要求太多，烦死了” | 没有指向对方的措辞时，按外界压力抱怨处理，不据此扣关系摩擦分。 |
| 一轮摩擦后解释“没别的意思” | 解释保留证据，不额外扣分、不升级为较强摩擦。 |
| 有多轮热情表达，同时明确说“不想再联系” | 保留拒绝证据并应用 32 分上限，提示尊重当前边界。 |
| 没有聊天记录 | 显示缺口；没有记录不等于零分。 |

## 复核与后续校准

历史日分、月年曲线会按新规则重新计算；新旧算式的绝对分数不可直接作为关系变化证据。月年汇总仍按对方回合加权，并保留不足 20 回合时对高于 32 部分的折算，因此日级与月年级均存在保守收缩。

规则词库可能误判反话、方言、工作交流和话题承接；媒体内容及线下相处也未进入模型。工作、日常等场景标签目前用于核对，未采用不同数值权重。现有自动化用例只能核对实现行为、计算一致性和边界条件，不能证明真实关系判断准确。

若未来要声称分数经过经验校准，需要先定义目标（如用户对当次回应质量的自评），在明确授权的数据上进行独立标注、按联系人隔离验证、报告误差与不同沟通场景表现；在此之前不展示“喜欢概率”或统计意义上的置信度。
