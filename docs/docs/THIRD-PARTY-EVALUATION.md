# 第三方项目接入评估

评估日期：2026-11-01

## hotcoffeeshake/tong-jincheng-skill

**结论：可吸收少量通用沟通原则，不作为运行时依赖或人格模仿功能。**

该仓库是面向模型的关系分析 Skill，主要提供提示和分析框架，不是可直接调用的代码库。它采用 MIT 许可证。可以参考的原则包括直接表达需求、不用测试或冷处理验证关系、尊重边界、鼓励对方自由回应。

不采用其“只要不确定对方是否喜欢你，就说明不喜欢”等确定性判断，也不复制其人物口吻、原始素材或研究文件。关系手记继续以可观察证据为基础，把可能解释标为不确定，不把模型推测写成对方事实。

## littlecodersh/ItChat

**结论：不接入关系手记主插件，也不作为当前微信窗口监听器。**

ItChat 是以 Python 编写的个人微信 API/机器人项目。其 README 展示通过 `auto_login()` 登录、注册收消息回调，以及使用 `send()` 发送消息；仓库标注 MIT 许可证。它不是针对已登录的 Windows 微信 4.1.15.56 前台窗口做 UI Automation 只读采集的适配器。把它加入主链路会新增独立登录和发送能力，超出当前本机只读监听范围。

如果以后确实要评估，应作为隔离的实验适配器单独审核登录、会话数据去向、可用性和停止机制；默认关闭，且不接触关系手记的正式资料库。

## 接入边界

- 回复、话题和关系分析仍以用户编辑确认后自行发送为准，不自动发消息。
- 外部分析框架只作为可选提示，不改变“事实 / 反复观察到的行为 / 推测”分层。
- 当前窗口监听继续优先评估针对微信与 QQ 桌面窗口的只读 UIA 方案。
