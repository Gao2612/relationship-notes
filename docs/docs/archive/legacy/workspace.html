    聊天仅在浏览器内存中处理；不调用 AI、不联网、不上传、不保存聊天。刷新或清除后消失，不改动原文件。

    支持的格式与大小

    UTF-8 TXT / JSON，最大 2 MiB，最多 10,000 条消息。TXT：每条“发送者: 内容”（支持中文冒号）；可带 [2026-10-21 09:00] 时间。也支持“[时间] 发送者”或“发送者:”单独成行，正文接在后续行。无表头 CSV、HTML、微信数据库和其他编码不支持。

    [2026-10-21 09:00] 小禾: 我住在杭州。
[2026-10-21 09:01] 我：你好！

{"messages":[{"sender":"小禾","text":"我喜欢摄影。","timestamp":"2026-10-21 09:00"}]}

    JSON 顶层仅有 messages 数组；每条 sender、text 为非空字符串，timestamp 可省略或为字符串。JSON 引用显示消息序号与原文件行号。
