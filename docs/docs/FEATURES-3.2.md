# 关系手记 3.2 功能入口与数据说明

## 功能入口

| 功能 | 入口 | 操作 |
|---|---|---|
| 证据定位 | 联系人画像依据、互动评分原文、话题依据、解释与复盘 | 打开上下文，突出原消息及前后各3条；Escape关闭。来源已删改或不能唯一定位时显示提示。 |
| 资料有效期 | 联系人档案 → 资料有效期与事项管理 | 设置截止日期，事项可完成/取消/过期/重开；待确认资料须先确认。新旧资料对照和历史仍保留。 |
| 本人计划 | 设置 → 我的计划状态与有效期 | 完成、取消、到期、重开；修改其他本人字段时保留未变计划的状态。 |
| 回复反馈 | 回复草稿 → 把编辑后的回复作为表达反馈 | 检查当前草稿，填写可选备注，明确保存为本人样例；可撤销本次保存。最多8条，每条240字，不从复制动作自动学习。 |
| 话题反馈 | 回复页下一步建议 | “已经聊过 / 不合适”隐藏当前相同依据的话题；在已隐藏列表恢复。明确暂停和等待回应提示不会被话题反馈屏蔽。 |
| 周/月复盘 | 行为记录 → 周/月复盘 | 选周或月及所属日期，查看话题关键词、计数、原文样本、未见本人后续回应的问题和当前跟进事项。 |
| 共享范围 | 设置 → 预览并限定DSH读取范围 | 限制首尾日期和最近1–500条消息，预览时间、截断及未知日期；应用即撤销旧授权，需重新开启。日期筛选限制聊天原文，已确认且有效的档案另行共享。 |

## 行为与兼容

- 周按上海日期周一至周日，月按自然月。未知消息日期不计入周期统计；问题后没有记录到本人回应只是线索，不保证问题真的未回答。复盘为本机规则整理，不新增模型调用。
- 截止日期含当天，上海当日结束后才过期。过期/完成/取消内容保留历史，但退出当前事实、话题与本人计划模型上下文。宿主读取也检查已知到期时间。
- 回复反馈只有用户确认保存后才影响后续生成；不是自动训练模型。话题反馈只影响本机候选，不代表联系人态度。
- 新消息使用持久messageId；旧ID和引用保留兼容。对完全缺少源ID的重复同文增量仍无法总是区分，见 [消息身份说明](MESSAGE-IDENTITY.md)。旧评分纠正如果无法唯一定位，不自动应用到多条消息，并提示重新核对。
- 反馈、事项状态、本人样例、复盘偏好和共享范围随现有IndexedDB保存与备份恢复；共享授权本身不恢复。
- 界面抽出7个视图工厂至src/views，页面总组装仍在workspace.js，后续可继续按职责拆分。

## 交付

源码构建与安装步骤见README。维护者在构建和验证后运行 `node tools/package-release.mjs --out <新交付目录>`，生成安装ZIP、SHA256和逐文件manifest；已有ZIP不会被静默覆盖。

微信/QQ监听、替代ExportWeChat、自动发送与主动搭话仍未开发启用。
